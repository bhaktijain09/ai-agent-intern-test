# Returns Policy (Legacy — Superseded)

**This document describes the returns policy that was in effect prior
to February 2026. It is retained for historical/support-ticket
reference only and must not be used to answer current customer
questions.**

## Old standard return window

Regular customers had **14 days** from delivery to return unused
items for a full refund.

Row+ members (formerly called "Row Rewards" members) had a **30-day**
window.

## Old return shipping cost

Return shipping was a flat $9.95 for all customers, with no free
return shipping tier.

## Why this changed

In February 2026, Aster & Row extended return windows and made return
shipping free for Row+ members as part of a broader customer
experience overhaul. See 01-returns-policy-current.md for the policy
that applies today.
