# Row Rewards Membership Benefits (Legacy — Superseded)

**"Row Rewards" was the old name for what is now called "Row+".
Retained for historical reference only.**

## Old benefits

Row Rewards cost $39/year and included a flat $2.00 shipping
discount per order (not free shipping), a 30-day return window (not
60), and a 5% member discount (not 10%). The program was renamed and
upgraded to "Row+" in February 2026.
