# Returns Policy

Aster & Row wants you to love what you bought. If something isn't
right, here's how returns work.

## Standard return window

Regular customers may return unused, unworn items in original
packaging within **30 days** of delivery for a full refund to the
original payment method.

Row+ members (our paid membership tier) get an extended **60-day**
return window on all purchases.

## Condition requirements

Items must be unused, unworn, and include all original tags and
packaging. Products marked "final sale" at checkout are not eligible
for return.

## How to start a return

Customers can start a return from the Order History page or by
contacting support with their order ID. A prepaid return label is
provided for domestic returns; return shipping is free for Row+
members and $6.95 for regular customers, deducted from the refund.

## Refund timing

Refunds are issued within 5–7 business days of the returned item
being scanned by the carrier, not from the day it is dropped off.

## Exchanges

Direct exchanges (same item, different size or color) are processed
as a return plus a new order, so the original charge is refunded and
a new charge is placed for the exchanged item.

## Damaged or defective items

Items that arrive damaged or defective are not subject to the
30/60-day window restrictions above — see the Warranty Policy for
defect coverage, which applies regardless of how long ago the item
was purchased within the warranty period.
